# Planning Session

- Produce an implementation plan, not code.
- Treat `prompt.md` and `sources/manifest.md` as the control documents.
- Prefer supplied source files and local repo checkouts over general knowledge.
- Read Markdown source conversions before consulting raw PDFs.
- Maintain planning artifacts under `output/`.
- Cite source IDs, filenames, repo paths, and sections/files for important claims.
- Separate verified claims, assumptions, pitch framing, and open questions.
- Ask for missing context instead of inventing details.
